# Creating Shares

Shares are the folders you’ll be putting your stuff in. To create a share:

1. Make sure your array is running.
2. Go to the **Shares** tab.
3. Click **Add Share**.
4. Type in the **Share name**. It's suggested to write it in all lower case as Unraid is case sensitive, but it isn't mandatory.
5. You can leave the rest of the options as they are and click **Add Share**.

If you have a cache drive, we will come back to that shortly. If you ever want to delete a share, it must first be emptied and then the delete checkbox will show.

### ❓ One share or multiple shares?

Whether you should have have one share with all of your data versus multiple shares is basically, personal preference. 

With **multiple shares**, you can **set different permissions** for each of them or have them on **specific drives**. So you'd probably want to separate your media, photos, and documents.

For your media, it's suggested to create a share called `data`, then a folder in it called `media`,  then create a folder for movies, tv, etc inside of that. So in the future if you ever want to automate your media with TRaSH Guides, the folder structure is already setup.
