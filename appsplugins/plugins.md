Unlike apps which are installed in their own containers, plugins are installed directly into Unraid. Which can potentially be problematic, causing some plugins to break after a major Unraid update. Also having too many plugins for the Web UI can slow it down. You can also find plugins on the Community Apps.

Unraid is updating rapidly so a lot of the cool plugins are being baked into Unraid itself. Here are some plugins you can take a look at. Quite a few of these will be mentioned in the App Installation guides.

| Plugins | Descriptions |
| --------- | --------- | 
| Appdata Backup    | Backups up your appdata folder    | 
| Folderview2    | Lets you group containers on the Docker tab   | 
| User Scripts   | Lets you run scripts automatically   | 
| Recycle Bin   | Keeps deleted files for X amount of days (including deleted from SMB)   | 
| Look through Dyanmix's Stuff    | Dynamix in general has cool stuff. Some of them were implemented into Unraid itself  | 
| NerdTools  | May come in handy for installing some nerdy stuff?   | 
| Python3 for Unraid  | Installs Python to do Python things  | 
| unbalanced    | Transfer files/folders between drives. Useful for when I had to empty out the drive I was replacing    | 
| Live Memory Tester for UNRAID    | Let's you test your memory while your server is on. This isn't complete magic, your system will still have to be very much unused. So can probably only have Plex running.    |
