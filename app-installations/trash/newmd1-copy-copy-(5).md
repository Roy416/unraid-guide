# qbitmanage

when you upgrade a movie, radarr doesnt fully delete the old version, this is where qbitmanage comes in. because it only delete 1 of the copies so the other one becomes unhardlinked which is in the torrents folder.

You could use builtin stuff in qbit to delete something after x amount of seeding time, but you might be like me where you want to seed it if the file is being used in your library and removed if it isnt.
